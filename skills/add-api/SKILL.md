# 接口开发流程

1. 读取路由、请求响应模型、已有异常处理和相关测试。
2. 查看任务板和此次需求适用的已确认规范；局部例外不得扩大到整个仓库。
3. 先定位现有实现，再作最小必要修改，新增注释使用中文。
4. 显式检查参数边界、错误路径和返回模型。沿用仓库现有架构，避免自行引入新分层。
5. 使用 `verify` 在固定快照上运行规范检查和测试；通过后再完成验收任务。
6. 如果修改了验证后的代码，重新验证。存在未自动验证的规范时在报告中说明。
